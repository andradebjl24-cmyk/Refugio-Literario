# 🌿 Refúgio Literário

### Um lugar onde cada livro esconde um mundo inteiro.

O **Refúgio Literário** é uma aplicação web de gerenciamento de biblioteca, desenvolvida com C# e ASP.NET Core MVC. O sistema permite explorar o catálogo literário, descobrir autores, organizar favoritos e acompanhar empréstimos, além de disponibilizar uma área administrativa para gerenciar o acervo e os usuários.

## ✨ Funcionalidades

- 📚 **Catálogo literário:** consulta e pesquisa de livros e autores.
- 🗂️ **Organização do acervo:** categorias, subcategorias, editoras e exemplares.
- 👤 **Conta de leitor:** cadastro, autenticação e perfil.
- 💜 **Favoritos e comentários:** recursos para personalizar a experiência de leitura.
- 🔄 **Empréstimos:** solicitação e acompanhamento de empréstimos e devoluções.
- 🛡️ **Painel administrativo:** gerenciamento de livros, autores, editoras, categorias, exemplares, usuários e solicitações.

## 🛠️ Tecnologias utilizadas

## ⚙️ Como executar

**Pré-requisitos:** [.NET SDK 10](https://dotnet.microsoft.com/download/dotnet/10.0), SQL Server e Visual Studio ou editor compatível.

1. Clone o repositório:

   ```bash
   git clone https://github.com/andradebjl24-cmyk/Refugio-Literario.git
   ```

2. Acesse a pasta do projeto e configure a conexão com o SQL Server no `appsettings.json`.

3. No diretório que contém o arquivo `.csproj`, execute:

   ```bash
   dotnet restore
   dotnet build
   dotnet run
   ```

4. Acesse no navegador o endereço exibido no terminal.

> **Observação:** a aplicação depende de uma instância do SQL Server acessível e de um banco de dados compatível com as migrations do projeto.
